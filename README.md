# Neon Snake - Fun Cool Game of the Day

A glowing neon version of the classic Snake game built with pure HTML5 Canvas and JavaScript.

## How to Play
- Use **Arrow Keys** or **WASD** to control the snake
- Swipe on mobile
- Eat the glowing pink orbs to grow and score points
- Avoid walls and yourself!
- High score is saved in your browser

## Play it
Open `index.html` in any modern browser, or host it on GitHub Pages!
